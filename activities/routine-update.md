Read the routine update report named in the additional instructions (a Markdown file in this project's temporary/ folder). It lists, item by item, what changed in the monitored source, each field before and after, quoted as read.
Find the files of this project that rely on those items (context/, notes, documents delivered before) and propose the updates file by file: what changes, where, and which item of the report it comes from. Show me the plan and wait for my approval before changing any file.
Do not invent: what the report does not say becomes a question to me. An item that affects no file of the project is listed as such.
