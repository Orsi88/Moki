# Activities

The activities that come with Moki: reusable requests a person picks in "Open in your AI tool". Each file is one activity: its frontmatter says its name, optional target (`uses: skill:<name>`, several distinct `skill:<name>` entries separated by commas, `agent:<name>`, `workflow:<id>` or `operation:<id>`) and which inbox files it needs (`files: required | optional | none`). Without `uses`, the request text below is required. An agent may have no skills. Several skills retain all their procedures and approval gates. `{files}` becomes the chosen files (a line with it is left out when there are none), a line that starts with `{no-files}` is kept only when there are none, and `{project}` becomes the project id. Existing single-target files remain valid.

These files are read-only in the app: duplicate one in Settings › Activities to change it. Your own activities live in `workspace/library/activities/`. The app's own actions (open the project, project context, prepare, plan, resume a run) are built in code. Guide: [docs/activities.md](../docs/activities.md).
